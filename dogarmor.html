DogArmor AI

AI-powered dog gear recommendation system using pose estimation

Problem

Pet owners struggle to choose properly fitting and safe gear due to lack of personalized sizing and posture-based insights.

Solution

Built an end-to-end AI system using YOLO pose estimation to analyze dog posture and generate real-time gear recommendations.

Tech Stack

Python, Flask, YOLO, Azure

Architecture

Image Input → YOLO Model → Flask API → Recommendation Output

Impact

  • Real-time inference with low latency
  • Scalable backend for continuous model updates
  • Improved recommendation accuracy through iterative training

Challenges

  • Pose estimation accuracy across dog breeds
  • Data labeling and dataset quality
  • Latency optimization for real-time inference

Future Improvements

  • Mobile app integration
  • Larger training dataset
  • Model optimization for faster inference
