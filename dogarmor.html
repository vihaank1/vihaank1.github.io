DogArmor AI

AI-powered dog gear recommendation system using pose estimation

Problem

Pet owners struggle to select properly fitting and safe gear due to lack of personalized sizing and posture-based insights. Most solutions rely on generic breed-based recommendations, which fail to account for real-world variation in posture and body structure.

Solution

Designed and built an end-to-end AI system that analyzes dog posture using YOLO-based pose estimation and generates real-time gear recommendations. The system processes image inputs, extracts key body features, and maps them to optimized gear suggestions.

Tech Stack

Python, Flask, YOLO (Computer Vision), Azure

System Architecture

Image Input → YOLO Pose Model → Feature Extraction → Flask API → Recommendation Engine → Output

Built a modular pipeline separating model inference, feature extraction, and API logic to enable independent scaling and future model upgrades.

Impact

  • Enabled real-time recommendation generation with low-latency inference
  • Designed scalable backend architecture for iterative model improvements
  • Reduced reliance on manual sizing by automating posture-based analysis

Challenges

  • Maintaining pose estimation accuracy across diverse dog breeds and positions
  • Building a reliable labeled dataset for training and evaluation
  • Optimizing inference latency for near real-time performance

Engineering Decisions

  • Chose YOLO for fast inference speed over heavier models
  • Separated model and API layers for scalability
  • Designed pipeline to support continuous retraining and dataset expansion

Future Improvements

  • Mobile-first deployment for real-time user interaction
  • Expanded dataset for improved generalization
  • Model optimization for faster inference and lower compute cost
