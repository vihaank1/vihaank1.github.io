DogArmor AI

A real-time computer vision platform that analyzes dog posture and generates personalized gear recommendations using AI.

Python YOLO Flask Azure Computer Vision

Problem

Pet owners often struggle to choose properly fitting collars, harnesses, and equipment. Traditional solutions rely on generic breed recommendations and fail to account for differences in body structure, posture, and behavior.

Solution

DogArmor AI processes dog images using computer vision models, extracts posture-based features, and generates personalized recommendations through a scalable backend pipeline.

Engineering Decisions

  • Selected YOLO architecture because real-time inference speed was critical.
  • Separated model inference from backend logic to support future model upgrades.
  • Designed modular pipelines for easier retraining and scaling.
  • Built API-first architecture for future mobile integration.

Technical Challenges

  • Maintaining accuracy across different breeds, sizes, and poses.
  • Creating reliable training data pipelines.
  • Balancing inference speed with model accuracy.
