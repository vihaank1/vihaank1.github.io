DogArmor AI

A computer vision platform exploring AI-powered posture analysis and personalized dog gear recommendations.

Python YOLO Computer Vision Flask Azure
GitHub Repository

Problem

Choosing safe and properly fitting dog equipment is difficult because traditional recommendations often rely only on breed information. Dogs vary significantly in body structure, size, posture, and behavior, creating a need for more personalized recommendations.

Solution

DogArmor AI explores an end-to-end computer vision pipeline that analyzes dog images, extracts visual features, and generates personalized gear recommendations. The system is designed around modular AI components that can improve through future dataset expansion and model refinement.

Engineering Decisions

Why YOLO?

The project prioritized efficient inference. YOLO was selected because real-time computer vision applications require strong speed and practical deployment characteristics.

Modular Architecture

The system separates model inference, feature extraction, and recommendation logic to allow independent improvements.

API-First Design

The backend structure was designed with future web and mobile integration in mind.
